캐릭터를 내 그림으로 바꾸기

여기부터는 소스를 받아서 고치는 분들을 위한 내용이에요. 그냥 쓰실 분은 넘기셔도 됩니다.

소스는 GitHub 저장소에서 받고, npm install 후 npm start 로 띄우면 돼요. 그림 3장이면 지금 움직임에 그대로 붙습니다.

생각할 때

① 그림 3장을 assets/ 폴더에 넣고, ② src/renderer/pet.html 의 <g id="pet"> 안을 이걸로 바꾸고,

<g id="pet">
  <image class="sprite s-idle" href="../../assets/idle.png" width="128" height="128" />
  <image class="sprite s-walk" href="../../assets/walk.png" width="128" height="128" />
  <image class="sprite s-busy" href="../../assets/busy.png" width="128" height="128" />
</g>

③ src/renderer/pet.css 맨 아래에 이걸 붙이면 끝.

.sprite { display: none; }
.mode-idle .s-idle,
.mode-fall .s-idle,
.mode-drag .s-idle { display: block; }
.mode-walk .s-walk { display: block; }
.busy      .s-busy { display: block; }   /* busy가 이기도록 맨 뒤에 */

그림 만들 때 지킬 것 4가지

이거 네 개만 맞추면 어색해지지 않아요.

발을 바닥에 붙이기

128칸 중 아래에서 4칸 위에 발이 오게. 더 위면 공중에 떠 보여요.

투명한 곳도 눌려요

그림으로 바꾸면 빈 구석까지 클릭 판정에 들어가요. 정확히 하려면 모양대로 투명한 <path>를 위에 덮으세요.

그림자는 하나만

앱이 바닥 그림자를 따로 그려요. 그림에 그림자를 넣었다면 #shadow 를 지우세요.

더 크게 하려면

PET_SIZE(index.js) · viewBox(pet.html) · #stage(pet.css) 세 곳을 같이 올려요.

바꾼 모습 확인은 npm run shot → shots/pet-walk-3x.png 를 열어보면 3배로 크게 볼 수 있어요.
움직이는 GIF/APNG 한 장만 넣어도 됩니다 (그럼 걷기 모션은 그림이 알아서).
직접 고치기 · 개발자용

마음에 안 들면 여기를 고쳐요

파일 하나에 역할 하나씩이에요.

src/main/walker.js걷는 속도 · 쉬는 빈도 · 떨어지는 힘
src/main/agent.js답변 말투 (짧게/길게) · 매번 물어볼지 말지
src/renderer/bubble.css말풍선 색과 글꼴
src/main/index.js캐릭터 크기 · 말풍선 크기 · 단축키
src/renderer/pet.html · pet.css캐릭터 모양과 움직임

파일 수정을 매번 안 묻게

agent.js 의 permissionMode 를 'default' → 'acceptEdits' 로.

답을 더 길게 받고 싶다면

agent.js 의 PERSONA 에서 "짧게 쓰라"는 문장을 지우면 돼요.

고친 뒤엔

바로 확인하고, 괜찮으면 설치 파일을 새로 만들어요.

npm start고친 걸 바로 띄워서 확인
npm run e2eClaude 연동이 안 깨졌는지 검사 (3~5분)
npm run dist설치 파일 새로 만들기 → dist/
npm run guide이 설명서 다시 만들기
실행 결과는 전부 logs/ 폴더에 쌓여요. 화면에 아무것도 안 나와도 정상이에요 — 거기를 열어보면 됩니다.
